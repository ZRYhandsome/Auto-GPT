# 素账 PlainLedger

**无广告、不套会员、账单能导入、能多人分账、数据自己拿着的记账工具。** 纯前端 PWA，零依赖、零账号、零服务器。

它回应的是一个在小红书、知乎、V2EX、Hacker News 和 GitHub 上被反复提出、却一直没被好好满足的需求（见仓库内 `research/` 目录的调研报告）：

> "以前免费突然付费就算了，充钱只能用一段时间，每添加几项就扣几项……找来找去，没有功能差不多的软件。"
> "不开会员就无法跳过的开屏广告，广告期间稍微晃一下手机就跳转到其他 app。"
> "相比起普通的记账 APP，本地 Excel 表格没有任何广告，而且能永久保存数据。"

## 功能

| 模块 | 说明 |
|---|---|
| 导入官方账单 | 微信支付「下载账单（用于个人对账）」与支付宝「开具交易流水证明」导出的 CSV 直接拖入；自动识别 UTF-8/GBK、表头位置、退款与失败交易；按交易单号指纹去重，重复导入不会重复计数。银行等通用 CSV 支持手动列映射。 |
| 自动归类 | 内置约 200 个商户/关键词规则 + 支付宝分类映射 + 微信交易类型映射；手改分类时一键生成"以后「关键词」都归到 X"的规则并回溯应用。 |
| 多人分账 | 成员只是本地标签；每笔可设付款人与平均/按金额/按比例分摊；自动算出谁欠谁、最少转账方案；可记录结算。 |
| 零账号共享 | 导出账本文件（可选 AES-GCM 密码加密），微信/AirDrop 发给伴侣或室友，对方「导入并合并」：同一记录以修改时间新者为准，重复导入的账单按指纹合并，删除以墓碑同步。 |
| 报表与预算 | 月/年收支、支出分类条形图、6 个月趋势、Top 商户、分类预算进度、成员分摊表；退款自动从支出里扣除。 |
| 数据主权 | 全部存在浏览器 IndexedDB；一键导出 JSON/CSV；可安装为 PWA 离线使用；没有统计埋点，没有网络请求。 |

## 运行

不需要构建。任意静态服务器即可：

```bash
cd plainledger
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

手机浏览器打开后「添加到主屏幕」即成为离线可用的 App。`samples/` 里有三份合成账单（微信 UTF-8、支付宝 GBK、银行 CSV）可用来试导入。

## 怎么从微信 / 支付宝导出账单

- **微信**：我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 用于个人对账 → 选时间范围 → 发送到邮箱，解压得到 CSV。
- **支付宝**：我的 → 账单 → 右上角「···」→ 开具交易流水证明 → 用于个人对账 → 选时间范围 → 发送到邮箱，解压得到 CSV（GBK 编码，可直接导入）。

这两条都是官方提供、用户本人发起的导出，素账不读取任何私有接口，也不需要无障碍、Xposed 等灰色手段。

## 测试

```bash
node --test tests/*.test.js          # 解析 / 归类 / 分摊 / 合并 / 加密 单元测试
python3 -m http.server 8765 &        # 冒烟测试需要本地服务器
node tests/smoke.playwright.mjs      # 浏览器端到端：导入→分账→规则→报表→导出→离线
```

冒烟脚本使用容器预装的 Playwright；本地运行请先 `npm i -D playwright` 或设置 `PW_GLOBAL` 指向全局安装路径。

## 目录

```

src/csv.js      账单解析、编码检测、指纹与去重
src/rules.js    分类表、内置规则、用户规则、规则建议
src/split.js    分摊份额、余额、最少转账结算
src/merge.js    账本文件格式、三向合并、AES-GCM 加密
src/db.js       IndexedDB 封装与内存退化
src/charts.js   Canvas 条形图 / 趋势图 / 进度条
src/app.js      路由与六个视图
tests/          node:test 单测 + Playwright 冒烟
samples/        合成账单及其生成脚本
```

## 第一版明确不做

不做实时自动同步流水（国内没有合法的个人交易接口，任何"自动"都只能靠灰色手段）；不做账号与云同步；不做 OCR/AI 归类；不做原生 App。

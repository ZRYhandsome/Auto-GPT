# 座次桌签

**粘贴名单 → 自动排会议座次 → 一键打印双面桌签。** 一个网页文件，双击就能用，不联网、不上传，名单只在本机浏览器里处理。

## 为什么做这个

它来自小红书上的需求调研（见仓库 `research/2026-10-01-xhs-radar/`）：

- 原帖 415 赞、79 条回复："我真的想求出一个自动排座位的软件，自动识别职级职称，还能导入部门排序，每次排会议座位都很相思。"
- 用"排座次、会议座次、座次表、桌签、主席台座次"搜一轮：
  - 热度前 20 的帖子合计约 4.5 万赞、5.7 万收藏，其中桌签教程约 2.3 万赞、2.8 万收藏，会议和宴请座次图约 1.9 万赞、2.7 万收藏。收藏多于点赞，说明大家是存下来、到时候照着手工做。
  - "高手 10 秒制作会议席位牌"有 1 万赞、1.6 万收藏，抓到的评论有一半是在评论区按口令领模板。
- 教程评论区问得最多的，正是这个工具直接做好的事：
  - "怎么批量啊""怎么做一百份"；
  - "四个字以上的咋办""字号设置不到 140"；
  - "文字旋转不过来""保存以后就没有翻转了"；
  - "人数是双数怎么排""以左为尊还是以右为尊""是拍照人的左边还是被拍照人的左边"。

## 功能

| 步骤 | 说明 |
|---|---|
| 名单 | 从 Excel 复制"姓名、职务、单位"三列直接粘贴；也支持逗号、顿号、空格分隔，以及"张 三"这种中间带空格的两字名。有表头时按表头认列，第四列"主 / 客"用于会谈。重名会提醒。 |
| 自动排序 | 先排地方党政领导（书记、正职、副书记、副职），再排部门领导（部厅 > 局 > 处 > 科 > 股，同层级正职在副职前），然后是秘书长、助理、调研员等其他职务。职务里写了"正处级""副科"等级别的按级别排。同档按"单位顺序"或粘贴顺序。只是起点，可以上下调。 |
| 主席台 | 以左为尊（党政机关）或以右为尊（商务、涉外）；单数 1 号居中、双数 1、2 号同时居中；可限定每排人数自动分排；图上写明"从台下看"还是"从台上看"。 |
| 会见会谈 | 主客对坐，客方面门；可选两方 1 号对 1 号、2 号对 2 号，或各按自己的朝向排。 |
| 座次图 | 打印（A4 横向），下载 PNG，下载 CSV 座次表（Excel 可直接打开）。 |
| 双面桌签 | A4 横向对折、A4 三折三角立牌、200×100 台卡插页、180×70 小号台卡（一页两人），也可自定义尺寸。上半面自动倒印，对折后两面都是正的。名字按版面自动定字号，四字以上自动缩小、两字名加宽字距。可选宋体、小标宋、黑体、楷体，黑色或红色，第二行印职务或单位，带折线和裁切线。打印时可另存为 PDF。 |

## 怎么用

**直接用：** 双击 `dist/座次桌签.html`，用 Chrome、Edge 或 Safari 打开即可。打印桌签时在打印设置里选"实际大小 / 100%"，不要选"适合页面"。

**改代码时：**

```bash
cd seatcard
python3 -m http.server 8766          # 开发时用模块版：http://127.0.0.1:8766/
node tools/build.mjs                 # 重新生成 dist/座次桌签.html
node --test tests/*.test.js          # 解析、排序、排座规则、桌签版式的单元测试
node tests/smoke.playwright.mjs      # 浏览器端到端，自带本地服务器；加 BASE=file://…/dist/座次桌签.html 测打包版
```

冒烟测试使用容器预装的 Playwright；本地运行请先 `npm i -D playwright`，或设置 `PW_GLOBAL` 指向全局安装路径。Chromium 不在默认位置时设置 `CHROMIUM`。

## 排座规则说明

- **左右以就座者自己的朝向为准。** 以左为尊时 2 号坐在 1 号左手；从台下看，2 号在 1 号右边。7 人时台下看到的是 7 5 3 1 2 4 6。
- **人数为双数时**，1、2 号同时居中，2 号仍在 1 号左手；6 人时台下看到的是 5 3 1 2 4 6。
- **会谈时客方坐面门一侧。** 门在侧面时，以进门方向看，客方坐右侧。
- **各地各单位惯例不同，以本单位要求为准。** 自动排序和规则都可以手动调整。

## 目录

```
index.html / styles.css / icon.svg    开发用的模块版页面
src/parse.js     名单解析（Excel 粘贴、表头、分隔符、两字名、主客列）
src/rank.js      按职务排序（地方领导、部门层级、正副、单位顺序）
src/layout.js    主席台和会谈的排座规则，导出 CSV
src/cards.js     桌签版式、分页、字号计算
src/render.js    座次图和桌签的 SVG
src/app.js       页面交互、打印、导出、本机保存
tools/build.mjs  打包成单文件 dist/座次桌签.html
tests/           node:test 单测 + Playwright 冒烟
```

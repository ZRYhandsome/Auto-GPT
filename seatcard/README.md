# 座次桌签

**粘贴名单 → 自动排会议座次 → 一键打印双面桌签。** 有 Windows / Mac 软件，也有一个双击就能用的网页文件。不联网、不上传，会议和名单只保存在这台电脑上。

## 为什么做这个

它来自小红书上的需求调研（见仓库 `research/2026-10-01-xhs-radar/`）：

- 原帖 415 赞、79 条回复："我真的想求出一个自动排座位的软件，自动识别职级职称，还能导入部门排序，每次排会议座位都很相思。"
- 用"排座次、会议座次、座次表、桌签、主席台座次"搜一轮：
  - 热度前 20 的帖子合计约 4.5 万赞、5.7 万收藏，其中桌签教程约 2.3 万赞、2.8 万收藏，会议和宴请座次图约 1.9 万赞、2.7 万收藏。收藏多于点赞，说明大家是存下来、到时候照着手工做。
  - "高手 10 秒制作会议席位牌"有 1 万赞、1.6 万收藏，抓到的评论有一半是在评论区按口令领模板。
- 教程评论区问得最多的，正是这个工具直接做好的事：
  - "怎么批量啊""怎么做一百份"；
  - "四个字以上的咋办""字号设置不到 140"；
  - "文字旋转不过来""保存以后就没有翻转了"；
  - "人数是双数怎么排""以左为尊还是以右为尊""是拍照人的左边还是被拍照人的左边"。

## 怎么拿到

| 用法 | 适合 | 怎么装 |
|---|---|---|
| **Windows 软件** | 单位电脑，最常见 | 双击 `SeatCard-版本号-Setup.exe`，一键装好、自动打开，桌面和开始菜单里都有"座次桌签"。装在当前用户目录下，**不需要管理员权限**。不能装软件的电脑用 `SeatCard-版本号-Windows-x64.zip`：解压后双击 `SeatCard.exe`。 |
| **苹果电脑软件** | Mac | 在 Mac 上执行 `cd seatcard && npm install && npm run dist:mac`，得到 `release/SeatCard-版本号-mac-arm64.dmg`（M 系列芯片）和 `-x64.dmg`（Intel）。也可以在 GitHub 上打包，见下面"打包"。 |
| **网页版** | 先试试、临时用 | 双击 `dist/座次桌签.html`，用 Chrome 或 Edge 打开。和软件是同一个界面，只是打印要走浏览器的打印窗口，PDF 在打印窗口里"另存为 PDF"。 |

安装包都没有做数字签名：Windows 可能提示"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"；Mac 上第一次打开如果被拦，到"系统设置 → 隐私与安全性"里点"仍要打开"。

## 用起来是什么样

1. **首页**：选会议类型新建（主席台 / 会见会谈 / 宴请圆桌），下面是"我的会议"，可以打开、查找（按会议名或人名）、**复制一份**（例会、同一批人再开一次）、删除（能撤销）。把 Excel、Word 名单文件直接拖进窗口，自动新建一场会议，会议名称从文件名或表格标题里认出来。
2. **名单**（左边）：
   - 导入：拖文件进来、按 Ctrl+V 粘贴、或点"导入 / 粘贴"，右边实时显示认出来的每一个人。支持 Excel（.xlsx）、Word（.docx 里的表格）、CSV（UTF-8 或 GBK）、TXT；表格上面的标题行、"序号"列、"姓  名"这种带空格的表头都能认。老格式 .xls / .doc / .et / .wps 会提示另存或直接复制粘贴。已有名单时可以选"加在后面（同名跳过）"或"替换"。
   - 像 Excel 一样直接改：回车到下一行，最后一行回车加一个人，↑↓ 上下移动，Alt+↑↓ 调整位次；拖动行首的把手调顺序，拖到"客方 / 主方"下面就换边；点"主 / 客"切换。
   - 自动按职务排序（规则见下），改了职务离开这一行就排到新位置；手动调过以后显示"手动顺序"，随时可以"重新按职务排序"，也可以设置单位顺序、书记是否在同级行政正职前。
   - 重名、空行、会谈没分出客方、人数超过一桌，都会在名单上方提醒。
3. **座次图**（右边）：按住一个座位拖到另一个座位上，两人互换；点一下选中，可以"位次提前 / 靠后""和别人换座""删除"。尊位、每排人数、1 号对 1 号、每桌人数、主陪 + 副陪或主人居中、看图方向都在上面一排。可以放大缩小，"左右怎么算"有图解。
4. **桌签**（右边另一页）：和打出来一模一样的预览，每张标着"未打印 / 已打印 / 有改动"。版式、字体、颜色、第二行印职务或单位、两字名加宽、折线裁切线都能选，选过的样式下次新建会议沿用。
5. **打印**：选打桌签还是座次图；打过一次以后再改了名单，默认**只打新增和改过的**，不用整沓重打。软件版可以直接"存为 PDF"，纸张大小一毫米不差。
6. **导出**：座次图图片（PNG，发微信、插 Word）、座次表（CSV，Excel 和 WPS 都能打开）。
7. **撤销**：每一步都能撤销、重做（Ctrl+Z / Ctrl+Y，Mac 上 ⌘Z / ⇧⌘Z），删除、互换、导入后的提示条上也有"撤销"。
8. **保存**：每一步改动都自动保存，不用点保存（按 Ctrl+S 会提示这一点）。

## 数据放在哪

- 会议和名单只保存在这台电脑上，不联网、不上传，没有账号。
- 软件版的数据在 Windows 的 `%APPDATA%\SeatCard`、Mac 的 `~/Library/Application Support/SeatCard`。
- 软件版每天第一次打开、每次关掉一场会议时，都会自动备份一份到数据目录下的"自动备份"文件夹，留最近 30 天（菜单"文件 → 打开自动备份文件夹"）。
- 换电脑：首页右上角"备份全部"导出一个文件，到新电脑上"从备份恢复"。同一场会议以修改时间新的为准。
- 网页版的数据在浏览器里，清理浏览器数据会清掉，重要的会议记得"备份全部"。

## 开发和打包

```bash
cd seatcard
npm install                          # 装 Electron 和打包工具
npm test                             # 单元测试：解析、排序、排座规则、桌签版式、导入、会议操作、保存、撤销
npm run smoke                        # 浏览器里把整个使用流程走一遍（打包版 dist/座次桌签.html）
npm run test:desktop                 # 真的启动桌面版，检查存 PDF、导出、自动备份（Linux 无屏幕时前面加 xvfb-run -a）
npm run app                          # 打开桌面版
npm run dist:win                     # 打 Windows 安装包和免安装 zip（在 Linux 上打需要装 wine）
npm run dist:mac                     # 打 Mac 的 dmg（要在 Mac 上执行）
```

- 开发时也可以 `python3 -m http.server 8766` 打开 `index.html`（模块版）；`node tools/build.mjs` 重新生成 `dist/座次桌签.html`。
- 冒烟测试用容器预装的 Playwright；本地运行先 `npm i -D playwright`，或用 `PW_GLOBAL` 指向全局安装的位置，Chromium 不在默认位置时设 `CHROMIUM`。
- 国内下载 Electron 慢，可以先设 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 和 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。
- **在 GitHub 上打包**：`.github/workflows/seatcard-desktop.yml` 会在 Windows 和 Mac 机器上各打一份，改了 `seatcard/` 推上去就自动打，打好的安装包在那次运行的 Artifacts 里。这个仓库是复刻来的，要先在仓库的 Actions 页面点启用。

## 排座规则说明

- **左右以就座者自己的朝向为准。** 以左为尊时 2 号坐在 1 号左手；从台下看，2 号在 1 号右边。7 人时台下看到的是 7 5 3 1 2 4 6。
- **人数为双数时**，1、2 号同时居中，2 号仍在 1 号左手；6 人时台下看到的是 5 3 1 2 4 6。
- **会谈时客方坐面门一侧。** 门在侧面时，以进门方向看，客方坐右侧。
- **宴请圆桌**默认以右为尊：主陪坐面对门的主位，主宾在主陪右手、副主宾在左手；副陪坐对面，三宾、四宾在副陪右手、左手，其余宾主交替。也可以选"主人居中"，客人按主宾、第二宾……在主人右、左交替往下坐。
- **按职务排序**：写了级别（正厅、副处……）的按级别；地方党政领导（书记、市长、人大主任、政协主席……）在部门领导前，副市长在局长前；部门按部厅 > 局 > 处 > 科 > 股，同层级正职在副职前；秘书长、助理、调研员、经理、总监等在后，没写职务的最后；"党组书记、局长"按最高的算。同一档按单位顺序、再按粘贴顺序。
- **各地各单位惯例不同，以本单位要求为准。** 自动排序和规则都可以手动调整。

## 目录

```
index.html / styles.css / icon.svg   模块版页面（开发用）
src/app.js          入口：首页和会议页切换、快捷键、桌面版菜单命令
src/home.js         首页：新建、我的会议、查找、复制、删除、备份恢复
src/editor.js       会议页：名单表格、座次图拖动互换、桌签预览、打印和导出
src/dialogs.js      导入名单、打印、排序规则、"左右怎么算"对话框
src/dom.js          图标、提示条、对话框、菜单等界面小工具
src/platform.js     网页版和桌面版的差别（打印、存 PDF、另存文件、自动备份）
src/meeting.js      一场会议的数据和操作（导入、增删、互换、只重打改过的、提醒）
src/store.js        本机保存、备份导出导入        src/history.js   撤销重做
src/importers.js    读 xlsx / docx / csv / txt（自己解压，不用第三方库）
src/parse.js        名单解析        src/rank.js     按职务排序
src/layout.js       主席台、会谈排座，导出座次表   src/round.js    宴请圆桌
src/cards.js        桌签版式、字号   src/render.js   座次图和桌签的 SVG
electron/           桌面版主进程（窗口、中文菜单、打印、PDF、自动备份）和 preload
electron-builder.yml  打包配置；tools/after-pack.cjs 在非 Windows 上给 exe 写图标和版本信息
build/              软件图标（icon.png、icon.ico）
tools/build.mjs     按依赖顺序打包成单文件 dist/座次桌签.html
tests/              node:test 单测；smoke（浏览器全流程）；desktop（桌面版）
```
